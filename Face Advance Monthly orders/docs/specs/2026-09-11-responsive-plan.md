# แผน Responsive — ระบบ MO (มือถือ + iPad)

วันที่ 2026-09-11 · สถานะ: **แผน (รอ boss เคาะการตัดสินใจ)**

## เป้าหมาย
ให้ใช้งานระบบ MO บน **มือถือ (~360–430px)** และ **iPad (~768–1024px)** ได้ดี — ปัจจุบันออกแบบ desktop-first (layout ยึด 100vh flex + ตารางกว้าง)

## Breakpoints ที่จะใช้
- 📱 **มือถือ**: ≤ 600px
- 📲 **iPad/แท็บเล็ต**: 601–1024px
- 🖥️ **desktop**: > 1024px
- 👆 **touch**: `@media (hover:none) and (pointer:coarse)` — สำหรับพฤติกรรมสัมผัส (แยกจากขนาดจอ)

## สำรวจสถานะปัจจุบัน
- ✅ มี `<meta viewport>` แล้ว
- ✅ มี @media บางส่วน: record-returns · EDITH · search · usermgmt (จูนไว้ ~640–1280px แนวแท็บเล็ต ยังไม่สุดมือถือจริง)
- ❌ **หน้าออเดอร์ (หลัก) + header + KPI + Dock + sidebar + ตาราง** แทบไม่มี mobile handling
- ⚠️ **~131 จุดที่ใช้ px คงที่** · ตารางกว้าง ~2000px (16 คอลัม)
- ⚠️ **ปัญหา touch:** Dock ใช้ `mousemove` (magnify) → สัมผัสไม่ได้ · ลากเลือกแทร็ค/สถานะ + ปฏิทิน ใช้ mouse events · tooltip/spotlight ใช้ hover

## แผนองค์ประกอบร่วม (shared)
1. **Layout 100vh** → ใช้ `100dvh/svh` กัน address bar มือถือดันจอ
2. **Header (.top)** — คอนโทรลเยอะ (โลโก้·เดือน·รีเฟรช·เมล·ค้นหา·ซูม·นำเข้า·ผู้ใช้·ออก) → มือถือ: ย่อเหลือ โลโก้ + เดือน + ปุ่ม "⋯" (เมนูรวมที่เหลือ) · ซ่อนซูม (ใช้ pinch แทน)
3. **Navigation แทน Dock** — Dock magnify เป็น mouse-only → มือถือ/แท็บเล็ต: **แถบเมนูล่าง (bottom tab bar)** 5 ไอคอน (แตะสลับหน้า) · desktop คง Dock เดิม
4. **KPI (.krow 3 คอลัม)** → iPad: 2 คอลัม · มือถือ: 1 คอลัม (เรียงลง) — กราฟ/การ์ดปรับ min-height
5. **Filter dropdown (.fdrop 15rem)** → มือถือ: เด้งเป็น **bottom sheet เต็มกว้าง** (ตอนนี้ absolute top-right จะล้นขอบจอ)
6. **Modal (นำเข้า/usermgmt)** → มือถือ: เต็มจอ (usermgmt ทำแล้ว · import ปรับ padding/max-height)
7. **Sidebar drawer (.sbpanel 34rem)** → มือถือ: เต็มกว้าง (max-width 96vw มีแล้ว · ปรับ font/ปุ่มให้แตะง่าย)

## แผนต่อหน้า (5 หน้า)
- **ออเดอร์** (หลัก): KPI stack · **ตาราง = จุดใหญ่สุด** (ดูการตัดสินใจ #1) · funnel→bottom sheet · sidebar เต็มจอ
- **บันทึกตีกลับ**: มี @media บ้างแล้ว → มือถือ: ฟอร์ม+รูป+การ์ดนับ เรียงลง · ปุ่มแตะง่าย
- **ออเดอร์ตีกลับ**: เหมือนหน้าออเดอร์ (ตาราง + การ์ด)
- **ค้นหา**: มี @media 900px → จูนมือถือ (ช่องค้น/toggle/การ์ด/ตาราง)
- **EDITH**: 3 คอลัม → มือถือ: **แท็บสลับ** (คิว / โต๊ะตรวจ / audit) แทนวางเรียง · ปฏิทิน+time picker คุมความกว้าง

## แผน Touch
- Dock → bottom nav (ข้างบน)
- **ลากเลือกแทร็ค/สถานะ** (mouse) → เพิ่ม touch events (touchstart/move) หรือ มือถือใช้ **แตะติ๊กทีละอัน** (ลากบนมือถือชนกับ scroll)
- **ปฏิทินลากเลือกช่วง** → รองรับ touch (หรือแตะ 2 ครั้ง = เริ่ม-จบ)
- hover tooltip/spotlight → touch: แตะ หรือปิด

## 🔑 การตัดสินใจที่ต้องเคาะ (boss)
1. **ตารางบนมือถือ** (สำคัญสุด): 
   - **(ก) การ์ด/ลิสต์** — แต่ละออเดอร์เป็นการ์ด (UX ดีสุดบนมือถือ · งานเยอะ)
   - **(ข) ตารางเลื่อนแนวนอน** — คงตาราง ปัดซ้ายขวา (เร็วสุด · ใช้แถบเลื่อนล่างที่มี · แต่แน่นบนจอเล็ก)
   - **(ค) ผสม** — iPad=ตารางเลื่อน · มือถือ=การ์ด (แนะนำ)
2. **เมนูมือถือ**: bottom tab bar (แนะนำ) / hamburger / คง Dock
3. **ลำดับหน้า**: เริ่มหน้าไหนก่อน (แนะนำ ออเดอร์ → ตีกลับ → ค้นหา → EDITH → บันทึกตีกลับ)
4. **iPad**: แค่ desktop ย่อ (ตารางเลื่อน) พอไหม หรือต้องปรับพิเศษ
