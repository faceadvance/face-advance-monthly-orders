# สถานะชำระ "บางส่วน" — design (เคาะแล้ว 2026-09-23 · ยังไม่ลงมือ)

## ที่มา
ออเดอร์ที่พัสดุมีปัญหาแล้วได้เงินไม่เต็ม เช่น ขนส่งจ่ายเงินเคลมไม่เต็มตามนโยบาย (เคสจริง: ออเดอร์ปี 2025 `เม.ย.!2593` ยอดขาย 2,490 ได้เงินเคลม 2,000)
ตอนนี้ `reconcile_order` เห็นเงิน COD ≠ ยอดขาย แล้วตั้งชำระเป็น `error` ทั้งที่ไม่ได้ผิด

## สิ่งที่เจ้านายเคาะ
1. **ทาง A** — เพิ่มค่าใหม่ใน `payment_status` คือ `บางส่วน` (ไม่ใช่แค่ป้ายติดกับ "ชำระแล้ว")
2. **นับเงินเหมือนชำระแล้วเต็มจำนวน** — แดชบอร์ด/การ์ด/รายงาน นับ `บางส่วน` = `ชำระแล้ว` ทุกที่ (ยอดขายและยอดชำระ = ยอดขายเต็ม)
3. ใช้ได้เฉพาะออเดอร์ที่สถานะจัดส่ง = `มีปัญหา`
4. เพิ่มช่อง **ยอดที่รับจริง** (`orders.paid_amount`) — ต้อง > 0 และ < ยอดขาย
   - โชว์ **เฉพาะใน sidebar** และเฉพาะตอนสถานะชำระ = บางส่วน · **ไม่โชว์ในตาราง**
   - โอนเงิน: คนกรอกเองตอนตั้งสถานะบางส่วน
   - COD: ระบบใส่ยอดให้อัตโนมัติจากรายการเงินเข้า ตอนบันทึกหรือนำเข้า
5. นำเข้า COD: ถ้าแถวไหน `ได้รับจาก = ทำเคลม` และยอด **น้อยกว่า** ยอดขาย → ถาม "ยืนยันชำระบางส่วนใช่ไหม"
   - ตรวจแบบนี้ **เฉพาะ ทำเคลม** (ขนส่ง/ระบบ ที่ยอดไม่ตรง → error เหมือนเดิม)
   - **ไม่ยืนยัน = ยกเลิกการนำเข้าทั้งไฟล์** · บันทึกมือทีละรายการ = เตือนแล้วไม่บันทึกอะไรเลย
   - ยืนยัน → ชำระ = บางส่วน · จัดส่ง = มีปัญหา · `paid_amount` = ยอดเงินเข้า

## จุดที่ต้องแก้ (สำรวจแล้ว)
- **DB:** CHECK `orders_payment_status_chk` · คอลัมน์ `paid_amount` + CHECK · ฟังก์ชันที่อ้างสถานะชำระ 10 ตัว: `app_sales_dashboard` · `reconcile_order` · `revert_recon_effects` · `app_import_cod_payments` · `app_save_order_tracking` · `app_edith_set_payment_status` · `app_edith_exchange` · `app_edith_issues` · `app_import_orders` · `get_months`
- **ตัวช่วยกลาง:** ฟังก์ชันเดียวบอกว่าสถานะไหน "นับเป็นจ่ายแล้ว" ให้ทุกที่เรียกใช้ กันตกหล่น
- **reconcile_order:** ออเดอร์ที่เป็น `บางส่วน` + เงิน COD จาก ทำเคลม ที่น้อยกว่ายอดขาย → คงบางส่วน ไม่เปลี่ยนเป็น error
- **frontend:** `main.ts` (PAYMENT_STATUSES · การ์ด · sidebar) · `util.ts` (badge) · `dashboard.ts` · `edith.ts` · `search.ts` · `import.ts` (กล่องยืนยัน) · `api.ts`

## เทสที่ต้องมี
บางส่วนต้องมี paid_amount · paid_amount ต้อง < ยอดขาย · เลือกได้เฉพาะ มีปัญหา · แดชบอร์ดนับเท่าชำระแล้ว · นำเข้า COD ทำเคลมยอดน้อยกว่า → ต้องยืนยัน · ไม่ยืนยัน → ไม่มีอะไรถูกบันทึก · ขนส่งยอดไม่ตรง → error เหมือนเดิม
