### `7bdb2e8` · 14:57 — คัดลอกข้อมูลหน้าตีกลับ + หมวดหมู่แจ้งเตือนตามสิทธิ์
**1) ➕ คัดลอกข้อมูล (หน้าออเดอร์ตีกลับ)**
- ปุ่ม **"คัดลอกข้อมูล"** ถัดจากช่องค้นหา — คัดลอกทุกแถวที่แสดงอยู่ (ตามตัวกรอง/คำค้น/การเรียง) เป็นแพทเทิร์น `เบอร์โทร : / ชื่อลูกค้า : / ยอดขาย : / เลขแทร็ค :` คั่นแต่ละรายการด้วย `---`
- ➕ **คอลัม "เลือก" ขวาสุด ตรึงไว้** (เหมือนคอลัมอัพเดตหน้าออเดอร์) — ติ๊กทีละแถว หรือ **คลิกค้างแล้วลาก**เลือกหลายแถว · ลากซ้ำบนที่เลือกไว้ = ยกเลิกเป็นชุด
- เลือกไว้ → ปุ่มเปลี่ยนเป็น **"คัดลอก (n)"** คัดลอกเฉพาะที่เลือก · ไม่ได้เลือก → คัดลอกทั้งหมดที่แสดงอยู่
- หัวคอลัมมี **ป้ายจำนวน + ปุ่ม ✕ ล้างการเลือก** · ข้อมูลในตารางเปลี่ยน (กรอง/ค้นหา/เรียง/เดือน/โหมด) → **ล้างการเลือกอัตโนมัติ**

**2) ➕ หมวดหมู่แจ้งเตือน + กรองตามสิทธิ์เข้าถึงหน้า**
- แบ่งเป็น **3 หมวด**: 📦 ตีกลับ · 📥 นำเข้าออเดอร์ · 💰 นำเข้าไฟล์ COD (ใหม่) · แต่ละหมวดมีไอคอน+สีของตัวเอง
- ➕ **ชิปกรองหมวด** ในกล่องแจ้งเตือน (โชว์เมื่อมี ≥2 หมวด · มีจำนวนต่อหมวด)
- 🔒 **กรองตามสิทธิ์ที่ server** (`app_can_page` + `app_notifications`) — ตีกลับ: ต้องเข้าถึงหน้าออเดอร์ตีกลับหรือออเดอร์ · นำเข้าออเดอร์/COD: ต้องเข้าถึงหน้าออเดอร์ → **RT+ / RTs ไม่เห็นเรื่องนำเข้าอีก**
- COD: เฉพาะที่นำเข้าจากไฟล์ (ข้ามการรับเงินแก้มือทีละรายการ) · limit 30 → **50** (มี 3 หมวดแล้ว)
- ⚠️ **บันทึกเหตุการณ์:** ระหว่างพัฒนา ฟรายเดย์อัปเดต RPC บน prod ก่อน deploy frontend → โค้ดเก่าไม่รู้จัก `kind='cod'` ทำให้แจ้งเตือน COD แสดงผิดเป็น "บันทึกตีกลับเพิ่ม" ให้ผู้ใช้ทุกคนเห็นชั่วคราว · ถอนออกทันทีแล้วใส่กลับพร้อม deploy รอบนี้ · **บทเรียน: การเปลี่ยนที่ frontend ต้องอ่านค่า ให้ deploy frontend ก่อนเสมอ**
